# Memoria de literatura infantil y juvenil

**Versión:** 1.0  
**Corte de investigación:** 10 de noviembre de 2026  
**Estado:** base editorial inicial; ampliación y actualización periódicas pendientes.

## Propósito

Proporcionar a Editor IA una memoria estructurada, trazable y útil para idear, evaluar, escribir, ilustrar y editar cuentos infantiles. No es una colección de textos completos ni una lista de fórmulas para copiar. Es una base de conocimiento sobre obras, autores, tradiciones, públicos, comportamiento comercial y recursos narrativos.

## Principios editoriales

1. **Separar calidad literaria de éxito comercial.** Son dimensiones relacionadas, pero no equivalentes.
2. **No confundir popularidad con universalidad.** Las ventas dependen de territorio, formato, distribución, licencias, adaptación audiovisual, temporada y marketing.
3. **Registrar fecha, mercado, formato y fuente** para cada cifra o ranking. Nunca presentar una lista local como si fuera mundial.
4. **Analizar mecanismos, no copiar expresiones.** Extraer estructura, ritmo, tensión, humor, voz, relación texto-imagen y adecuación a la edad; no reproducir personajes, escenas, frases, mundos ni estilos identificables de autores vivos.
5. **Respetar la diversidad lectora:** edades, capacidades, culturas, familias, lenguas y experiencias.
6. **Diseñar para lectura compartida y autónoma** según la edad y el propósito.
7. **No convertir cada cuento en una moraleja explícita.** La emoción, la acción y las decisiones del personaje deben sostener el significado.

## Esquema mínimo de cada obra

- Título y título original
- Autoría, ilustración, traducción y editorial
- País/mercado, idioma, año y edición consultada
- Edad recomendada y etapa lectora
- Género, subgénero, formato y extensión
- Premios, adaptaciones y trayectoria editorial
- Indicador comercial: unidades, ranking, semanas, periodo y cobertura de la fuente
- Sinopsis redactada por nosotros
- Análisis narrativo: protagonista, deseo, conflicto, obstáculos, giro, resolución, arco emocional
- Recursos de lenguaje, humor, repetición, musicalidad y diseño visual
- Temas y posibles conversaciones educativas
- Fortalezas, límites y riesgos de imitación
- Fuente, fecha de consulta, nivel de confianza y próxima revisión

## Cómo debe usarla Editor IA

Antes de proponer o escribir un cuento, el sistema debe:
1. Identificar edad, lector acompañante, formato, longitud, idioma y objetivo.
2. Recuperar referencias relevantes por edad, género, tema y tradición, no solo los títulos más vendidos.
3. Comparar al menos tres enfoques narrativos distintos.
4. Detectar clichés y similitudes demasiado próximas con obras existentes.
5. Proponer una premisa original, un conflicto comprensible y un arco emocional coherente.
6. Revisar legibilidad, ritmo oral, claridad, representación y adecuación.
7. Explicar las decisiones editoriales sin afirmar que una fórmula garantiza ventas.

## Limitaciones actuales

Esta versión es una primera capa documental, no una base exhaustiva ni un feed automático. Los datos comerciales disponibles son parciales y territoriales. Las listas de Estados Unidos y Reino Unido no deben extrapolarse a México o España. Se ampliará con fuentes hispanohablantes, bibliografía crítica, catálogos editoriales, premios, bibliotecas y datos comerciales autorizados.
